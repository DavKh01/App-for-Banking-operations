# Banking AML, Fraud & Risk Analytics (ՀՀ Բանկային Գործարքների Վերլուծություն)

Ծրագիրը նախատեսված է բանկային գործարքների AML (Anti-Money Laundering), խարդախությունների, ռիսկերի գնահատման և դրամական հոսքերի վերլուծության համար:
Համակարգում ներառված է **ֆիզիկական անձանց** և **իրավաբանական անձանց** գործարքների առանձնացումը թաբերով (Tabs):

### Իրավաբանական անձանց դեբետ հաշիվների նախածանցներ՝
- `3020200`
- `3001200`
- `3001600`
- `3000200`
- `3001000`
- `3001400`

Մնացած բոլոր դեբետ հաշիվներով գործարքները դասակարգվում են որպես **ֆիզիկական անձինք**:

## Ինչպե՞ս գործարկել ծրագիրը համակարգչում (Local Run)

### 1. Տեղադրել անհրաժեշտ գրադարանները՝
```bash
pip install -r requirements.txt
```

### 2. Գործարկել Streamlit հավելվածը՝
```bash
streamlit run app.py
```

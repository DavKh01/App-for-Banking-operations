# Banking AML, Fraud & Risk Analytics (ՀՀ Բանկային Գործարքների Վերլուծություն)

Ծրագիրը նախատեսված է բանկային գործարքների AML (Anti-Money Laundering), խարդախությունների, ռիսկերի գնահատման և դրամական հոսքերի վերլուծության համար:



---

## Ինչպե՞ս գործարկել ծրագիրը համակարգչում (Local Run)

### 1. Տեղադրել անհրաժեշտ գրադարանները՝
```bash
pip install -r requirements.txt
```

### 2. Գործարկել Streamlit հավելվածը՝
```bash
streamlit run app.py
```

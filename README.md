## Ինչպե՞ս գործարկել ծրագիրը համակարգչում (Local Run)

### 1. Տեղադրել անհրաժեշտ գրադարանները՝
```bash
pip install -r requirements.txt
```

### 2. Գործարկել Streamlit հավելվածը՝
```bash
streamlit run app.py
```

## Արագության ճարտարապետություն (Polars + Calamine + DuckDB + Parquet)

Տեսքը, էջերը, վերնագրերը և վերլուծության տրամաբանությունը անփոփոխ են, սակայն ներսում աշխատում է արագ stack.

- **Calamine** — Excel (`.xlsx`/`.xls`) ֆայլերը կարդացվում են անմիջապես, առանց openpyxl-ի։
- **DuckDB** — CSV/TSV-ն ուղղակիորեն stream արվում է Parquet, իսկ բոլոր ծանր aggregated հաշվարկները (dashboard, Benford, AML ցուցանիշներ, հաճախորդներ/հաշիվներ, money flow, pivot) կատարվում են SQL-ով։
- **Parquet** — յուրաքանչյուր բեռնված/մաքրված dataset պահվում է սեղմված Parquet ֆայլում ժամանակավոր պանակում (`banking_aml_parquet`): Session-ում պահվում է միայն փոքր նկարագիր, ոչ թե ամբողջ տվյալը։ Կրկնօրինակ բեռնումները ընթանում են cache-ից։
- **Polars** — մաքրումը, ռիսկերի հաշվարկը, ֆիլտրերը, նույնացումը և գրաֆի եզրերի նախնական խմբավորումը վեկտորացված են։ NetworkX-ը մնում է միայն cycle/SCC ալգորիթմների համար, բայց այժմ ստանում է նախապես խմբավորված եզրեր՝ առանց `iterrows()`-ի։

Արդյունք՝ մեծ ֆայլերը բեռնվում են մեկ անգամ, յուրաքանչյուր էջի վերագործարկման ժամանակ վերհաշվարկ չի արվում (Streamlit cache), իսկ արդյունքները մնում են նույն տեսքով։
